Hermes - Privacy Policy

Hermes is a personal assistant app built and used by one person, Josh Grayline. It is not offered to the public.

What it accesses: With my permission, Hermes accesses my own Gmail, Google Calendar and Google Drive so it can summarise email, manage my calendar and organise my files.

Where data goes: Data is processed on my own private server. To carry out tasks, some content is sent to an AI model provider for processing. Data is never sold, never used for advertising, and never shared with anyone else.

Google user data: Hermes's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access: Access can be revoked at any time at myaccount.google.com/permissions.
